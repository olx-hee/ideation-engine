## 0. 요약 판정

직전 「단순 병렬 분업 = 품질 우위 불성립」은 **그대로 유효**하다.  
**갱신되는 것:** 「**Map-Reduce(병렬 발산 → 적합한 종합 1콜)** + 종합=Solar-Pro4」는 n=6 실측상 **단일(Flash) 대비 품질↑·비용↓가 동시에 관측**된다. 제품 목표의 “분업으로 더 의미 있게”에 **조건부 재개**다.

수위는 **잠정 성립(working hypothesis 채택·코드 반영 정당)** — 아직 **확정 성립**은 아니다(n=6, 종합모델 민감, Solar 이중 노출 교란 가능).

프레임: 헤드라인을 「아무 분업이나 품질↑」로 쓰지 말고 **「조율(reduce) 있는 분업 + 종합 모델 선정」**으로 한정하면, 예전 금지와 **화해 가능**.

다음(제품 목표): **① 교란 제거 재현(Solar-alone vs MR) 소규모 → ② 창의 쐐기를 Map-Reduce에 붙이기**를 병행. 발표용 미터/B1은 이번 범위 밖(요청대로).

**Blocker 0 / High 0 / Medium 4 / Low 3**

## 1. [요청①] 결론 갱신 — 「품질 우위 불성립」이 깨지나?

### 1-1. 원자료 재집계

| 실험 | 주장 | 재집계 | 판정 |
|------|------|--------|------|
| mapreduce | 단일 3.92 / 분업만 3.50 / MR 4.50, 승 6/6 | 동일; 비용 0.00078 / 0.00026 / **0.00124** (MR÷단일 ≈**1.59**) | ✅ |
| synth-compare | MR-Solar 4.42 / $0.00029 vs 단일 4.17 / $0.00081 (≈**2.76×** 저렴) | rows와 일치 | ✅ |
| 분업만 < 단일 | 3.50 < 3.92 | ✅ 이전 결론(조율 없는 병렬은 손해) **유지** |

### 1-2. 무엇이 갱신되는가

| 이전 결론 | 갱신 |
|-----------|------|
| 단순 fanout 분업 ≠ 품질 우위 | **유지** (분업만 최하) |
| 분업의 제품 가치 ≈ 비용·다양성·난이도 라우팅 | **확장:** Map-Reduce(+좋은 synth)면 **품질도 목표에 기여할 수 있음** |
| “분업으로 더 좋게” 구상 | **「병렬 + 종합」형태면 잠정 실증** — 단순 병렬로는 아님 |

### 1-3. 「성립」수위 (제품 목표 기준)

**잠정 성립 — 제품에 넣어도 된다. “증명 완료”는 아직이다.**

근거(채택 쪽):
- 원인(조율 실패) ↔ 처방(reduce)이 통제실험과 **정합**
- synth-compare에서 **품질·비용 동시** 개선 관측
- 코드에 `purpose: synthesize` 분리 — 측정 목표와도 맞음

근거(확정 보류):
- **n=6**, 심판 실패 시 단일심판 가능
- **종합 모델 민감:** GPT-4o-mini synth는 단일보다 나쁨(3.75) → “Map-Reduce” 일반화가 아님
- **교란:** fanout 사업성 각도에 이미 Solar-Pro4, synth도 Solar → 자기 원안 편집·이중 노출. **Solar 단독 4관점**과 비교 없음
- 단일 baseline이 Flash이지 Solar가 아님 → 「분업 > 최강 단일」이 아니라 「MR-Solar > 단일 Flash」

**제품 목표 한 줄:** 단일 프롬프트 대비 의미 = 이제 **「다각도 생성 + 저가 강종합」파이프**로 잠정 충족. 더 굳히려면 교란 제거 재현 한 판.

## 2. [요청②] AI 사용법 — Map-Reduce가 정직한 분업인가?

### 2-1. 사용법 정의 (권장)

```
Map:  각도별 저~중가 모델 병렬 발산 (다양성·역할 분리)
Reduce: 선정된 종합 모델 1콜이 원안을 병합·중복제거·보완
미터: generate vs synthesize 분리 (§5). 사용자 체감 비용은 합산 고지.
```

이게 정직한 이유는:
- “네 모델이 알아서 특화”가 아니라 **역할이 코드에 명시**됨
- 조율 실패를 **숨기지 않고 단계로 해결**
- 오픈 라우팅(OpenRouter)+레지스트리로 측정·교체 가능 → 초기 「도구로 보조·측정」과도 맞음

### 2-2. 종합 모델 민감성 — 정직하게 다루기

| 사실 | 제품 함의 |
|------|-----------|
| Solar synth 최상, Flash 비싸고 품질 중간, Lite·mini 약함 | **SYNTH는 레지스트리 1급 설정** — “아무 모델이나 reduce” 금지 |
| 선정에 벤치 의존 | `SYNTH` 옆에 **골든 세션 회귀**(교체 시 n 소규모 재측정) |
| Solar가 fanout에도 있음 | 사용법 문서: 「종합은 편집자, 각도 배정과 독립 튜닝」— 가능하면 fanout에서 synth와 **중복 최소화**(다양성·교란↓) |

코드 반영(`SYNTH=Solar-Pro4`, ux→Pro4, synthesize 프롬프트)은 사용법과 **일치·타당**.

### 2-3. 제품 목표 매핑

| 목표 | Map-Reduce 기여 |
|------|-----------------|
| 단일 프롬프트보다 의미 | ✅ 구조화된 다성→종합 파이프 (잠정 품질 이득) |
| 가볍/무겁 라우팅 | 부분 — 지금은 **idea 경로**. ice/analyze는 별 축 유지 |
| 특화 맞춤 | 각도 특화 주장 없이 **역할(발산 vs 종합)** 분리가 더 정직 |
| OSS·측정 | ✅ purpose 분리·벤치 하네스. (미터 UI 실측은 범위 밖이나 제품 완성엔 여전히 필요) |

## 3. [요청③] 프레임 — 품질우위를 넣어도 되나?

### 화해안 (제품·정직성)

| 금지 (유지) | 허용 (조건부) |
|-------------|----------------|
| 「분업이면 항상 품질↑」 | 「**Map-Reduce(발산∥ + 종합)** 이고 **종합 모델이 벤치된 경우** 단일 Flash 대비 품질↑·비용↓가 **관측됨(n=6, 잠정)**」 |
| 「각도 특화 모델이라 이김」 | 「다양 원안 + **조율 단계**가 품질을 만든다」 |
| 분업만(fanout)을 품질 스토리에 넣기 | 분업만 = 다양성·저비용 초안, **최종 품질은 synthesize 후** |

직전 「품질우위 헤드라인 금지」는 **단순 병렬**을 겨냥한 것이었고, 새 실측과 **모순되지 않는다.**  
헤드라인을 바꾸려면 주어를 **분업 → Map-Reduce(+SYNTH 선정)** 로 바꾼다.

**권장 제품 프레임 (발표 아님, 로드맵/README 내부용):**  
`난이도 라우팅 + Map-Reduce(품질·비용 잠정 이득) + 다양성 발산 + 정직 계측`

## 4. [요청④] 다음 우선순위 (제품 목표)

발표 일정 여유 → **확정 실험만 붙잡고 창의를 미루지 말 것.** 다만 교란 1개는 싼 비용으로 막는 편이 제품 신뢰에 이득.

| 순위 | 할 일 | 이유 |
|------|-------|------|
| **1** | **교란 제거 미니 재현** (각 n≈6): (A) 단일 Solar 4관점 (B) MR-Solar (C) fanout에서 Solar 제외+Solar synth | “종합 파이프” vs “Solar가 강해서” 분리 → 사용법 확신 |
| **2** | **창의 쐐기를 Map-Reduce에 확장** | 종합 프롬프트를 “세련된 4개”만이 아니라 **교차 리믹스·이상한 하이브리드 1개 강제·제약 카드** — 1041 가이드와 직결, 품질 점수 밖 차별화 |
| **3** | SYNTH/ANGLE 골든 회귀 고정 | 모델 교체 시 제품 회귀 |
| **4** | 무거움(analyze/report) 라우팅·reasoning 정합 | 초기 “무겁=맞는 AI” 축 — idea MR과 별개로 계속 |
| (범위 밖이나 제품 완성) | meter 실측·B1 | 사용자가 발표 제외로 둔 항목 — **실서비스 전에는 여전히 필요** |

**확정(n·심판 확대) vs 창의:**  
전면 확정 대실험을 **먼저 끝낼 필요 없음.** **미니 교란 제거(1) 후 창의(2) 착수**가 제품 목표에 최적. 창의 실험이 품질 점수를 다시 떨어뜨리면 그때 n을 키운다.

## 5. 코드·방법론 짧은 메모 (제품 리스크)

## 6. 한 줄 결론

**단순 분업 품질우위는 여전히 거짓이고, Map-Reduce+벤치된 종합(Solar)은 제품 목표상 “의미 있는 분업”을 잠정 되살린다. 프레임은 ‘조율 있는 분업’으로 좁혀라. 다음은 싼 교란 제거 한 판 뒤에 창의 쐐기를 reduce에 붙여라.**
