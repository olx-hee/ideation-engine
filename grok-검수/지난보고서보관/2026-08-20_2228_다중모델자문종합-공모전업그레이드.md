## 0. 네 모델이 **거의 같은 말** (채택 권고)

1. **업그레이드 대상은 “모델 더 넣기”가 아니라 “심사에 보이는 제품 실체”**다.  
2. 간판을 **「다중 LLM이 자동으로 더 창의」→「팀이 뻔하지 않은 답을 고르게 하는 퍼실리테이터」**로 옮긴다.  
3. 벤치가 반증한 **이종 자동 MoA / LLM-judge 창의 점수 자랑은 금지.**  
4. 2주 코어 = **병렬 후보(합치기 없음)+이견 보존 + 사람 시드 + 시중검색(신선도) + 짧은 데모 + 원가/가격 한 장.**  
5. 다중 LLM의 정직한 자리 = **창의 후보 테이블 + 생성≠검증**, 객관 kind는 **단일 최적 라우팅.**

## 2. 창의성 — 합쳐진 실행안 (우선순위)

| 순위 | 무엇을 | 누가 강조 | 비고 |
|------|--------|-----------|------|

| **P0** | **시중검색·신선도 게이트** (유사 사례/링크, `이미있음·변형·공백`, 공백 아니면 재발산) | Claude·Grok·Composer·GPT(근거충돌) | 측정 C축→**제품 기능**. Claude는 “이미 있어요 30초 격파” 데모 심장으로 |
| **P0** | **사람 시드 게이트** (시드 없으면 발산 불가, 출력에 시드 라벨/기여 %) | Grok·Claude·GPT | “GPT가 다 한 거 아냐?” 선제 방어 |
| P1 | **제약·렌즈 fanout** (같은 강모델×직교 제약; 모델 섞기보다 제약 섞기) | **Claude 독자 강조** | diversity에서 제약 효과가 컸다는 서사. 다중모델 병렬과 **병행 가능**(제약+이종 1장) |
| P1 | **Dissent Ledger** (반대이유·성립조건·재검토 시점) | **GPT** (이름까지) | P0 이견 UI의 데이터 모델로 흡수 |

**충돌 정리:** Claude는 “기본은 모델 섞지 말고 제약”, Composer/Grok는 “발산만 2~3모델 병렬”.  
**Grok 종합 채택:** 데모 기본 = **사람시드 + (제약 렌즈 2장 OR 모델 2장) 병렬·무합침 + 시중배지**. “모델 12개”는 금지. 이종성은 **검증·검색 쪽**에 두는 편이 Solar 편중 방어에 더 셈(Claude·2143과 정합).

## 4. 심사 데모 — 하나로 고정할 스크립트 (8분)

네 모델 데모를 **한 스토리로 합침:**

1. **같은 목표·같은 시드** → ChatGPT(또는 단일 매끈 1안) vs IdeationEngine.  
2. **시드 → 병렬 카드(합침 없음) → 시중 배지 → 팀이 잠복/공백 쪽 픽 → 이견이 보고서 하단.**  
3. **(선택) “이미 있음” 빨간 배지 → 제약 추가 재발산 → 공백 후보** (Claude 격파 비트).  
4. **정직 30초:** 이종 자동종합은 짐 / 창의=사람+다양성+시중 / 생성≠검증.  
5. **미터:** kind별 실모델 라벨 + 원가 (Solar 전지배라고 말하지 말 것).

기억에 남을 장면(GPT): **다수안 고른 뒤 Dissent에서 소수안+조건 반전.**
