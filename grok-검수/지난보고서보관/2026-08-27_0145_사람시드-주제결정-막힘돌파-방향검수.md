## 1) 시드 게이트 — “AI가 다 함” 방어로 충분한가 / 함정

### 판정: **필요·타당. 단독으로는 불충분. 진입장벽은 설계로 줄일 수 있음.**

| | |
|--|--|
| **왜 타당한가** | 2228 P0과 동일 논리. 입력이 사람 관찰이어야 ChatGPT 원샷과 데모에서 갈라진다. “시드 없으면 AI 버튼 비활성”은 그 경계를 **제품으로 강제**한다. |
| **왜 불충분한가** | 게이트만으로는 심사/사용자가 “결국 AI가 주제 뽑았네”로 읽는다. 방어 완성은 **(a) 근거 시드 원문 노출 (b) 후보 복수 + 사람 최종 선택 (c) 탈락 후보·이견 잔존 (d) “AI가 해석·묶기, 결정·시드는 사람” 배지**까지다. |
| **정직성** | 셀프체크대로 **중간 지대**가 맞다. “사람이 다 함” 금지. “AI 보조 묶기 + 사람 결정”이 정직한 한 줄. |

### 함정 (진입장벽·품질 편차)

[Medium] **전원 시드 필수 → 로비 교착**  
· 문제: 1명 미입력 시 팀 전체 대기 → 이탈·호스트가 시드 대신 입력 → human-first 붕괴.  
· 제안: 기본은 「**호스트 포함 최소 k명**(예: 과반 또는 2명+) 시드」로 AI 활성. 전원 대기는 **오프라인 동기 모드 옵션**. 미제출자 시드는 “미참여”로 attribution에 남김.

[Medium] **얇은 시드 세탁**  
· 문제: “배달 불편” 한 줄 → AI가 멋진 주제 문장 → 겉보기엔 AI 창작.  
· 제안: 후보 카드에 **시드 원문 인용(따옴표) 필수**, 윤문 주제와 분리 표시. 최소 길이(예: 15자)·“관찰/불편 1문장” 힌트만 — 에세이 강제 금지.

[Low] **호스트 시드 대필**  
· 재현: 시간 없다고 호스트가 전원 시드 작성.  
· 제안: memberId 바인딩( eventual B1 ) 전에도 UI에 “본인 입력” 강조; 데모 스크립트에 각자 타이핑 장면 고정.

**“GPT가 다 한 거 아냐?”에 대한 답:** 게이트만으로는 **부족**. 게이트 + **원문 attribution + 사람 픽**이면 **데모·심사 방어로 충분**에 가깝다. 기여 %는 있으면 좋지만 P0 필수는 아님(환각·과장 위험 — 원문 인용이 더 정직).

## 2) A의 “AI 시드 묶기” vs 반증된 자동종합

### 판정: **다른 작업이다. 단, UX/카피가 ‘한 방으로 합쳐 줌’이면 같은 함정.**

| 반증한 것 (하지 말 것) | A가 해도 되는 것 |
|------------------------|------------------|
| 여러 **LLM 생성물**을 자동 합성해 **품질 우위** 주장 | 여러 **사람 시드 텍스트**를 묶어 **후보 주제** 제안 |
| 이종 MoA / 자동 synth를 “더 창의”로 판매 | 입력 출처가 사람, 출력은 **선택지**, 결정권 사람 |
| 단일 “최종 정답” 자동 확정 | 후보 3 + attribution, **팀이 고름** |

**왜 방법론적으로 다른가**  
벤치가 깨뜨린 것은 “모델끼리 섞으면 아이디어가 더 좋아진다”는 **생성 품질 클레임**이다. A는 **퍼실리테이션(클러스터·명명)**에 가깝다. 입력이 사람 시드면 ChatGPT 무맥락 주제 생성과도 갈라진다.

**그래도 함정인 경우**

[High] **후보 1개만 자동 확정 / “추천 확정” 기본값**  
· 문제: 사실상 AI가 주제 결정 → human-first 위반 + 자동종합과 체감 동일.  
· 제안: 항상 ≥2~3 후보, 기본 선택 없음, 진행 버튼은 “팀이 고른 뒤”.

[High] **Attribution이 LLM 해석만** (인계 §4 셀프체크와 동일)  
· 문제: “서연의 시드에서”라고 붙여도 잘못된 매핑이면 정직성 붕괴.  
· 제안: (1) 카드에 **시드 원문 그대로** (2) 가능하면 id 참조 강제 스키마(시드 id 리스트) (3) 호스트가 attribution 수정 가능.

[Medium] **묶기를 다시 이종 앙상블로 키우기**  
· 제안: A kind는 **단일 저~중가 모델 1회**면 충분. “여러 모델이 주제를 합쳐 더 좋다” 금지(2228·1855와 동일).

**결론:** 사람 시드 입력 + 사람 최종 선택 + 원문 attribution이면 **OK (자동종합 재도입 아님)**. “AI가 합쳐줌”을 품질 서사로 밀면 **또 함정**.

## 3) B(막힘→돌파 방향) — 유용 vs 사고 대체 / 절제선

### 판정: **조건부 유용. 시중검색 ‘이미있음’·명시적 막힘에 묶으면 P0 서사 강화. 상시 온디맨드면 위험.**

| 유용한 지점 | 위험한 지점 |
|-------------|-------------|
| market 게이트가 막은 뒤 **재발산 자극** (2228 데모 “이미 있어요→재발산”) | 막히기 전·매 턴 “AI에게 물어보기” → 팀 사고 스킵 |
| **역량 조건부 방향 2개** (완성 아이디어·피치 아님) | 완성 솔루션·차별점 문장까지 대필 |
| 디자이너 예처럼 **렌즈 힌트** | 순위·“최적안”·점수 부여 |

### 절제선 (권고 — 제품 규칙으로 박을 것)

1. **트리거:** 기본은 `market=이미있음`(또는 호스트가 “막힘” 체크)일 때만 노출. 상시 FAB는 후순위.  
2. **출력:** 방향 제목 + 한 줄 질문형 힌트 **2개**. 구현 스펙·카피·점수 금지.  
3. **결정:** 팀이 방향 고르거나 **둘 다 버리고** 사람 문장 입력 후에만 다음 단계.  
4. **역량:** 프로필은 **힌트 가중**이지 역할 강제가 아님(“당신 각도만 하라” 복귀 금지 — 인계 1차 이탈과 동일).  
5. **정직 카피:** “돌파를 AI가 했다” 금지 → “막혔을 때 다시 볼 **각도 제안**”.

[Question] B를 A와 같은 슬라이스에 넣을지 — 데모 심장만 보면 **A+market 재발산**이 먼저; B UI는 market 카드의 “막혔을 때” 버튼으로 흡수하는 편이 절제에 맞음.

## 4) 2228 P0 정합 · 지금 배선해도 되나

### 정합 매핑

| 2228 P0 | 이번 A/B | 정합 |
|---------|----------|------|
| 사람 시드 게이트 (시드 없으면 발산 불가, 시드 라벨) | A: 시드 없으면 주제 AI 비활성 + 근거 시드 | **정합·앞당김** (발산 전 **주제 결정**에도 시드) |
| 시중검색 신선도 | B가 ‘이미있음’과 연결 | **정합** (B는 market의 회복 UX) |
| 병렬 후보 + 이견 보존 (합치기 없음) | A는 주제 후보 병렬에 가깝고, **아이디어 발산 병렬·dissent는 별개** | **부분** — A가 #1을 **대체하지 않음** |
| 자동 synth 금지 | A 묶기가 “한 주제 확정”이면 위반 | 설계대로면 OK |

### 배선 권고

| 순서 | 무엇 | 이유 |
|------|------|------|
| **지금 OK** | **A MVP**: 시드 입력 → (최소 k) → kind 1회 묶기 → 후보 3+원문 attribution → 팀 선택 | human-first·주제 회의 정체성·2228 시드 P0의 가장 정직한 제품화 |
| **같이/직후** | **시중검색 카드**가 주제·아이디어에 붙는 UI (백엔드 있어도 프론트 미연결이면 데모 심장 공백) | 2228 #2; B의 전제 |
| **A와 병행하되 포기 금지** | **아이디어 단계 병렬 후보+이견** | 2228 #1. A만 배선하고 이거 스킵하면 다시 “말만 다중/말만 시드” |
| **A 다음 슬라이스** | **B** = market ‘이미있음’ → 방향 2개 (상시 챗 아님) | 절제선 유지 |
| **하지 말 것** | A 묶기를 다중모델 MoA로 키우기 / 실행 스텝 배분으로 되돌리기 / “사람이 다 함” 카피 | 이탈·반증 재도입 |

**한 줄:** **지금 A 배선해도 된다** — 단 **“시드 P0 완료”로 선언하려면** 발산 단계에도 시드 라벨이 남아야 하고, **공모전 P0 패키지 완료는 여전히 병렬+이견+시중 UI**까지다.

## 최종 답 (인계 4문항에 직답)

1. **게이트: 타당·필요, 단독 불충분.** 원문 attribution+사람 픽까지가 방어. 진입장벽은 **최소 k·짧은 시드·대필 방지**로 완화.  
2. **A 묶기 ≠ 반증된 앙상블** (입력이 사람, 출력이 후보, 결정이 사람일 때). 단일 합성·품질 서사화하면 **동일 함정**.  
3. **B: ‘이미있음’ 뒤·방향만·온디맨드(막힘 트리거)면 유용.** 상시·완성안 대필이면 위험.  
4. **A는 지금 배선 OK·2228 시드와 정합.** 병렬·이견·시중 UI를 대체하거나 “P0 끝”으로 치면 **비정합**. B는 market과 묶어서.
