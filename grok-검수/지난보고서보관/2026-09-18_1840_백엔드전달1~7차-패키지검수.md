## 3. 보안 (기본 포함)

| 항목 | 판정 |
|------|------|
| **키 노출** | `config.js`에 `baseUrl`·`useMock`만 — **프론트에 시크릿 없음 ✓** |
| **리프레시 토큰** | HttpOnly · Secure · SameSite=Lax · Path 제한 · **회전 + 재사용 시 전량 무효화** — 상용 기준 설계 ✓ |
| **401 처리** | `api.js` 단일 재시도 + `NO_RETRY` 목록 + 동시 401 refresh 1회 병합 ✓ / WS `4401` 재연결 ✓ |
| **XSS** | `App.escape`(5문자) 존재·사용 중. 단 `innerHTML` 조립 **55곳** |
| **헤더** | `X-Content-Type-Options` · `Referrer-Policy` · `noindex` ✓ — **CSP 없음** |
| **익명 규칙** | "서버 직렬화 계층 한 곳에서 거르고 **테스트도 만들라**"고 명시 — 설계 품질 높음 ✓ |

[Medium·보안] **액세스 토큰이 `localStorage`/`sessionStorage`(`ie.state`)에 저장**
· `app.js:26-27` — "로그인 유지"면 localStorage. XSS 1건이면 **토큰 탈취 + 세션 조작**.
· 완화되어 있는 것: 수명 1시간, 리프레시는 HttpOnly.
· 제안: (a) `vercel.json`에 **CSP 추가**(인라인 스크립트 정리 필요) (b) 가능하면 액세스 토큰은 **메모리 보관 + 새로고침 시 refresh**로.

[Low·보안] **방 코드 6자리(≈31^6) 열거** — 별도 초대 토큰 없음. 회원 로그인 필수 + `SESSION_FULL`/`STARTED`/`KICKED`로 완화되지만, 백엔드 요구사항에 **`/sessions/lookup` 시도 rate limit**을 한 줄 넣을 것 권장(현재 문서에 명시 없음).

[Question·보안] `POST /billing/checkout` — 결제 확정은 **웹훅으로만**이라고 docs/01에 명시돼 있어 방향은 맞다. 웹훅 **서명 검증**은 6차 문서에 들어 있는지 확인 권장.

## 4. 잘된 점 (유지)

1. **3중 동기화 구조** — `03-API-전체-목록.md` · `endpoints.js` · `mock.js`를 같은 생성기에서 뽑고, 검사기가 어긋남을 잡는다. 74개 규모에서 차집합 0은 수작업으로는 안 나온다.
2. **완료 기준 = 촬영 장면** — 차수별 시나리오 192개가 곧 데모 스크립트. "끝났다"의 정의가 모호하지 않다.
3. **결정 이력의 정직성** — `친구-확인요청.md`가 "명세대로 쓸 수 없어 제안대로 쓴 것"을 근거·파일·줄까지 남긴다. 22건 중 [결정됨→반영] 표시가 정확했다(실물 대조로 확인).
4. **가짜 서버 2종** — 백엔드 없이도 전 흐름이 돌아, 백엔드 지연이 프론트를 막지 않는다.
5. **익명 규칙을 최상위 제약으로** — "가장 중요"로 못 박고 표로 정리 + 서버 필터링 + 테스트 요구.
