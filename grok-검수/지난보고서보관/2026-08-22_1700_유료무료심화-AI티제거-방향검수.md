# PART A — 유료→무료 심화

## A1. 「무료 75%」타당성

| 층 | 판정 |
|----|------|
| Perplexity = 검색→랭킹→종합→인용 **골격** 복제 | **중~상 맞음.** Brave/그라운딩+우리 LLM+URL 저장으로 골격 가능 |
| Gamma = LLM 아웃라인·JSON 복제 + 테마/PPTX 렌더가 난제 | **맞음.** ③⑤가 유료 고유에 가깝다 |
| 「무료 75%」 | **기능 체크리스트로는 과하지 않음.** 다만 심사·사용자 체감 품질(자동 미려함·인용 신뢰)까지 넣으면 **60%대에 가깝게 과대**될 수 있음 |

**과대평가 지점:** “75% 도달”이 **제품 완성도 75%**로 읽히면 위험.  
**과소평가 지점:** 공모전 목적함수에서는 Gamma의 25%(픽셀 미화)가 **필수 아님** — 1549와 동일.

**채택 문장:** 「파이프라인 **골격**은 무료/초저가로 대부분 대체 가능. 자동 디자인·논문급 인용 신뢰는 의도적으로 비움.」

## A2. 인용 리랭커 “공모전엔 불필요” — 위험·안전장치

**판단:** 공모전·해커톤 초기 아이디어에서 **논문급 리랭커는 불필요**에 **동의**(1549·2334).  
**위험:** 리랭커 없는 채 **URL을 ‘근거’처럼 붙이면** 틀린/무관/광고 페이지가 “출처”로 보임 → 정직성·심사 역풍.

**최소 안전장치 (이것만은):**
1. **출처 = URL + 짧은 스니펫**을 세션에 저장 (LLM 기억만으로 “신규/사실” 금지).  
2. UI 라벨: `이미 있음 / 유사 / 공백·미확인` — **확정 사실이 아님**을 드러냄.  
3. **상위 N개만** 보여주고, 가능하면 **도메인 다양성**(같은 사이트 도배 방지).  
4. 검색 본문을 프롬프트에 넣을 때 **구획·길이 상한**(인젝션).  
5. (여유 시) 생성≠검증: 조사 요약과 **다른 모델**로 한 줄 크로스체크.

리랭커 ML 자체는 후순위.

## A3. Gamma 대체 슬라이드 — 넣을 가치 vs 후순위

| | 판정 |
|--|------|
| 지금(2228 P0 이전) 본구현 | **비추** — 산만. 1549·2228과 동일 |
| 가치 | **후순위 내보내기 1종**으로만. 피치 패킷(시드·이견·시중 배지)이 본체, 슬라이드는 포장 |
| 데모 1장 실험 | OK — “넣어도 된다”≠“지금 제품 코어” |

**예외:** P0 데모에서 “제출물 형태”를 30초만 보여줄 때 Marp **고정 템플릿 1개** 정도는 허용. 파이프라인 R&D·AI티 제거 대규모는 아님.

## B2. 절제선 — 튀지 않으면서 AI티 없음

사용자 우려 **동의.** 손그림 Open Peeps·강한 디스플레이 세리프·과한 모션은 2024~26 **또 다른 유행 티**(“탈AI 키트”)로 읽히기 쉬움.

**우리 맥락(팀 회의 웹앱·공모전) 절제선:**

| 해도 됨 | 하지 말 것 |
|---------|------------|
| 뉴트럴·저채도 팔레트 1세트(토큰) | 손그림 캐릭터를 브랜드 전면에 |
| 가독 산세리프 1 + 절제 세리프/디스플레이는 **제목만·1종** | 전면 손글씨·Excali 전용 룩 |
| 여백은 “비움”이 아니라 **실데이터로 채움** | 장식용 화려한 모션 |
| 사진 0~1장(제품/현장감), 남용 금지 | 스톡 히어로 콜라주 |
| Lucide 등 **절제 아이콘** | 일러스트로 빈 화면 메우기 |

원칙: **도구처럼 보이게** (Notion/Linear에 가까운 절제), **일러스트 포트폴리오처럼 보이지 않게.**
