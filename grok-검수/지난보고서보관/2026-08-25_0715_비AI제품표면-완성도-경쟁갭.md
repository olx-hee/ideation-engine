# 비AI 제품 표면 검수 — 필요성 · 완성도 · 경쟁 갭 · 업그레이드

**범위:** AI 오케스트레이터·모델 라우팅·미터·게이트·벤치 제외.  
**대상:** 세션 흐름(프로필→생성→로비→4단계), 영속화, 투표, 방식 UI, 초대/협업, 보안(비AI), 문서 정합성.  
**기준일:** 2026-08-25  
**판정 한 줄:** 핵심 뼈대(각도·방식·타이머·세션 저장)는 실동작하나, **진짜 팀 협업·분석→보고서 루프는 아직 시연 골격** — 유사 서비스 대비 가장 큰 갭은 실시간 협업·침묵 브레인·내보내기·역할/권한.

| **주제 추천(mockRecommendTopics)** | 있으면 좋음 | 규칙 목업 | AI 제외 관점에서도 “팀 역량→주제”는 유효. 깊이 얕음 |

### 판정 요약 (필요성)

- **유지·강화:** 각도 배분, 방식 3종 UI, 4단계 퍼실리테이션, 타이머, 세션/아이디어/투표 영속, 정직성 배지.

## 2. “구현 완료” vs 실제 (정직성)

README §6은 비AI에 대해 대체로 정확하다(팀원 목업·분석 수치 시연·실시간/인증 미구현).  
다만:

[Medium] `ROADMAP.md:33-40,78-84` — Mongo를 아직 “진행 중/연결 남음”으로 기술  
· 문제: README/CLAUDE는 Mongo ✅. 문서 충돌 시 최신 검수·커밋 우선이지만 ROADMAP이 오도.  
· 제안: ROADMAP ②를 완료로 갱신하고 다음을 “초대 라우팅·폴링·B1”으로 재정렬.

[Medium] `src/api.js:3` — “App은 아직 목업 플로우” 주석 스테일  
· 세션/ice/ideas/votes는 이미 연동.  
· 제안: 주석을 “join·분석 UI는 미연동”으로 수정.

[High] 제품 약속 vs Analyze/Report  
· 문제: README “결과를 자동으로 묶어 준다” / 분석·보고서 단계는 **시연 고정**. 투표만 실데이터.  
· 재현: 아이디어 제출 → 분석 화면 — 테마가 제출과 무관.  
· 제안: AI 없이도 **규칙 클러스터(키워드/수동 테마 라벨)** 또는 “사람이 테마명 입력 → 투표” MVP. AI 연결 전에도 수렴 루프가 닫혀야 함.

[High] 온라인 모드·초대  
· 문제: 링크 복사만 되고 **입장·공유 뷰 없음**. 모드 분리가 카피 차이 수준.  
· 제안: P0 비AI = (1) `/s/:id` 조인 화면 (2) `api.join` (3) 폴링으로 ice/ideas 동기. WebSocket은 후순위(ROADMAP ③과 동일).

[Medium] SCAMPER / Six Hats 미영속  
· 문제: 방식 선택 가치가 “화면만 다름”으로 남고, 세션 자산이 안 됨.  
· 제안: ideas와 동일 스키마로 lens/hat 필드를 붙여 저장, 또는 자유 발산과 같은 `ideas[]`에 `meta.method` 기록.

[Low] 좋아요·참여 체크리스트  
· like 로컬 only, “제출 ✓” 전원 고정 — 실협업 착각 유발. 시연 배지 유지 또는 제거.

[Question] App.jsx 단일 거대 파일  
· 유지보수성만 이슈. 제품 기능 우선순위와 무관하면 이연 OK.

## 3. 유사 서비스 대비 — 우리가 없고 그들이 있는 것

비교군: **Miro / Mural / FigJam**(화이트보드·라이브 워크숍), **Ideaflip / GroupMap / Stormboard**(퍼실리테이션·투표·단계), **IdeaScale**(장기 캠페인 — 우리 범위 밖).

| 그들이 보통 가진 것 | IdeationEngine | 갭 심각도 |
|---------------------|----------------|-----------|
| **실시간 동시 편집·커서** | 없음 | High (온라인 약속) |
| **초대 링크로 실제 입장** | 목업 | High |
| **침묵/프라이빗 스크래치 → 일제 공개** | 없음 | Medium–High (각도 철학과 잘 맞음) |
| **친화도 클러스터링(드래그 그룹)** | 없음(분석 시연) | High (수렴) |
| **닷 보팅 / 익명 투표 / 결과 숨김** | 투표 API는 있으나 테마가 가짜 | Medium |
| **진행자 역할(잠금·단계 강제·Summon)** | 호스트 구분 UI 약함 | Medium |
| **공유 타이머(전원 동기)** | 로컬 타이머(+서버 phase) | Low–Medium (오프라인 공유화면엔 충분할 수) |
| **템플릿 라이브러리** | 방식 3종 고정 | Low (의도적 좁힘 OK) |
| **내보내기 PDF/이미지/CSV** | PDF stub | Medium |
| **슬랙/지라/노션 연동** | 없음 | Low (초기엔 불필요) |
| **액션 아이템·후속 태스크** | 없음 | Medium (해커톤엔 “다음 할 일 3줄”만으로도 충분) |
| **참여자 분석(누가 얼마나 기여)** | 목업 참여자 수 | Low |

### 우리가 상대적으로 강한 비AI 축 (유지)

1. **프로필→각도 강제 분산** — 보드 도구는 “자유 스티커”가 기본; 구조적 역할 배분은 Ideaflip/GroupMap류에도 약함.  
2. **방식(SCAMPER/Hats)이 화면을 실제로 바꿈** — 템플릿 링크가 아니라 in-flow.  
3. **4단계 강제 퍼실리테이션** — Miro는 자유 캔버스라 진행자가 약하면 붕괴; 우리는 레일.  
4. **정직성 표기(시연용)** — 상용 경쟁사는 과장 수치 흔함; 차별 가능.

→ **포지션:** “무한 화이트보드”가 아니라 **해커톤/짧은 팀 세션용 가이드형 퍼실리테이터**. Miro를 이기려 하지 말고, Ideaflip/GroupMap의 **단계·투표·침묵** + 우리 **각도**를 조합하는 쪽이 맞다.

## 4. 업그레이드 후보 (비AI만, 우선순위)

### P0 — 제품 약속 닫기 (AI 없이도)

1. **초대 조인 + 폴링 동기** — 온라인 모드·로비 목업을 실기능으로.  
2. **분석 수렴 MVP** — 제출 아이디어 목록에서 호스트가 테마 묶기 / 또는 단순 키워드 그룹 → 그 id로 투표.  
3. **보고서 = 세션 실데이터** — 투표 상위 N, 원문 인용, 참여자·시간·방식. 시연 Score/설문 제거 또는 접기.  
4. **SCAMPER/Hats → ideas 영속**.

### P1 — 퍼실리테이션 품질

5. **침묵 발산 모드** — 타이머 동안 타인 아이디어 숨김 → 종료 후 공개 (각도 철학 강화).  
6. **호스트 단계 잠금** — 참가자는 현재 phase만, 호스트만 next.  
7. **PDF/Markdown 내보내기** — stub 제거.  
8. **액션 아이템 3칸** — 보고서 하단 “다음에 할 일”.

### P2 — 품질·신뢰

9. **B1 멤버 토큰**(링크+짧은 코드).  
10. **각도 배정 UX** — 수동 재배정, 4명 초과 시 각도 재사용 안내.  
11. **ROADMAP/api.js 주석** 정합.  
12. App 분리(유지보수) — 기능 후.

### 굳이 지금 안 해도 되는 것

- Miro급 무한 캔버스·와이어프레임  
- IdeaScale급 장기 캠페인·거버넌스  
- 무거운 회원가입(익명 토큰이면 충분 — ROADMAP과 동일)

[Medium] SCAMPER/SixHats 미영속 — `IdeaScamper`/`IdeaSixHats`

[Medium] 온라인 모드 카피 vs 실체 — “나중에 합류·브리핑” 미구현.

## 6. 최종 판정

| 질문 | 답 |
|------|----|
| 각 부분이 다 필요한가? | **각도·방식·4단계·타이머·영속**은 필요. 데모 멤버·가짜 QR·시연 점수는 시연용. 온라인 모드·보고서는 **약속 대비 미완이면 빼거나 완성**해야 함. |
| 전부 구현됐나? | **뼈대 ✅ / 협업·수렴·보고서 ❌~⚠️.** Mongo·자유발산·투표 API는 됨. |
| 경쟁 대비 추가 기능? | 실시간·침묵 공개·클러스터·역할·내보내기·후속 액션. |
| 업그레이드할 만한 기존 기능? | **각도+침묵 결합**, **방식 영속**, **투표를 실테마에 연결**, **보고서 실데이터화**, **초대 조인**. |

**다음 한 방 (비AI):**  
`초대 조인 + 폴링`과 `분석=실아이디어 테마(수동이라도) + 보고서 실데이터`를 같은 슬라이스로 닫으면, AI 없이도 “팀 세션 도구”로 데모 가능하고 경쟁 갭의 절반이 줄어든다.
