## 0. 요약

1. **덜 알려진 준수 LLM은 Nemotron만이 아니다.** 2026년 중반 기준 DeepSeek V4 Flash, GLM 5.2, MiniMax M3, Qwen3 계열, Kimi, gpt-oss-120b, Mistral, Gemma 4 등이 벤치·실사용에서 반복적으로 거론된다.
2. **위 후보 대부분이 OpenRouter에 이미 올라와 있다.** IdeationEngine 오케스트레이터의 “한 API로 다공급사” 전략과 정합한다. (`:free`·슬러그는 수시 변경 → 배포 직전 재확인 필요)
3. **작업별 특화 AI도 더 있다.** 조사(Elicit·Consensus·Gemini Deep Research), 덱(Gamma·Beautiful.ai), 회의록(Fireflies 등), 데이터(Julius) 등이 사용자 예시와 같은 장르다.
4. **적용 가능성:** OpenRouter LLM 라우팅은 설계와 맞고 장래 구현에 적합. Perplexity·Gamma·Elicit은 API가 있어 **부가 기능(조사/덱)** 자리. NotebookLM·Notion AI는 제품 UI 중심이라 **서버 임베드가 어렵고**, Manus는 **다른 제품(자율 에이전트)**에 가깝다.
5. **이번 조사는 코드·README·설계 문서에 반영하지 않았다.** (요청: 적용 안 함)

## 1. 조사 범위와 한계

### 1-1. 한 일
- “잘 안 알려졌지만 성능 준수한” 오픈웨이트·중견 LLM 후보를 웹·벤치 정리물에서 수집
- 각 후보의 **OpenRouter 노출 여부**를 모델/공급사 페이지·공식 블로그로 교차 확인
- 사용자 초반 예시(퍼플렉시티 / 제미나이 / NotebookLM / Notion AI / Manus)와 같은 **작업 특화** 제품을 확장 조사
- IdeationEngine(세션·발산·분석·보고서 + 오케스트레이터)에 **붙일 수 있는지**만 가능성 평가

### 1-2. 하지 않은 일
- 실제 API 호출·벤치 재측정·요금 실측
- 코드/어댑터/레지스트리 구현
- 심사 README·ORCHESTRATOR 문구 수정

### 1-3. 해석 시 주의
- 모델명·가격·`:free` 목록은 **2026년 6~8월 공개 자료** 기준. OpenRouter 카탈로그는 자주 바뀐다.
- “덜 알려짐”은 **일반 사용자·대중 브랜드 인지도** 기준이며, 개발자 커뮤니티에서는 이미 유명할 수 있다.
- 중국 랩 모델은 성능·가격이 강해도 **데이터 학습 약관·호스팅 지역** 이슈가 있다(해커톤/학교 맥락에서 중요).

## 2. 덜 알려진(또는 중견) 준수 LLM 후보

### 2-1. OpenRouter가 2026-06에 “지금 중요한 오픈웨이트 4개”로 꼽은 것

출처: [The Open Weight Models that Matter: June 2026](https://openrouter.ai/blog/insights/the-open-weight-models-that-matter-june-2026/)  
Artificial Analysis Intelligence Index(v4.1)·OpenRouter 가중 평균가를 인용한 정리.

| 모델 | AA Index (인용) | 대략 가격(in/out $/M, OR 가중) | 한 줄 포지션 | OpenRouter |
|------|-----------------|--------------------------------|--------------|------------|
| **DeepSeek V4 Flash** | 40대 | ~$0.054 / $0.242 | 에이전트·코딩 **가성비 Pareto** | ✅ |
| **GLM 5.2** (Z.ai) | **51 (오픈 1위권)** | ~$0.447 / $3.31 | 계획·장시간 코딩, Opus급 대체 후보 | ✅ |
| **MiniMax M3** | 44 | ~$0.098 / $1.21 | **이미지·비디오 + 장문** | ✅ |
| **NVIDIA Nemotron 3 Ultra** | 48 | ~$0.423 / $2.61 (+`:free` 루트) | 미국 오픈웨이트·배포/스택 스토리 | ✅ |

**세부 메모**

- **DeepSeek V4 Flash**  
  - MoE, 긴 컨텍스트(자료상 ~1M급), SWE-bench 등에서 오픈웨이트 최상위권에 근접한 Flash 변형.  
  - 1차 API는 저가이나 **학습용 데이터 이용** 가능 약관이 거론됨 → 서부 no-train 호스트는 대체로 더 비쌈.  
  - 톤/글쓰기보다 **기술·에이전트**에 강하다는 평가가 많음.  
  - IdeationEngine: ice/idea **저·중가 티어**, 대량 콜에 유리. 한국어 톤은 골든픽스처로 검증 필요.

- **GLM 5.2**  
  - 오픈웨이트 품질·에이전트 벤치 상단. 토큰을 많이 쓰는(thinking) 경향 → **출력 비용 주의**.  
  - IdeationEngine: analyze/report·교차검증 **고품질 티어** 후보. P1에서는 목업 단가에 넣고 P2에서 실측.

- **MiniMax M3**  
  - 텍스트만이 아닌 **네이티브 멀티모달**. 스크린샷·다이어그램·장문 문서.  
  - 라이선스가 MIT가 아닐 수 있음(Community License·상용 조건) → 상용화 시 법무/고지 확인.  
  - IdeationEngine: 현재 코어는 텍스트 세션. **화이트보드 사진·PDF 첨부**를 넣을 때 유력. 당장은 후순위.

- **Nemotron 3 Ultra**  
  - 이미 팀 창의성 스토리에 등장한 축. OR에 유료·`:free` 경로 모두 거론.  
  - IdeationEngine: 데모·무료 티어 쇼케이스·미국 벤더 스토리에 적합. **무료 = 상용 $/세션에 $0 영구 가정 금지**(ORCHESTRATOR §5와 동일).

### 2-3. OpenRouter 포함 여부 — 종합 판정

| 질문 | 답 |
|------|----|
| Nemotron만 OR에 있나? | **아니오.** DeepSeek·Qwen·NVIDIA·GLM·MiniMax·Kimi·Llama·Mistral·Gemma 등이 카탈로그에 있음 |
| “한 키로 다 부르나?” | **예.** OpenAI 호환 엔드포인트 + 모델 슬러그. 오케스트레이터 어댑터 1개로 흡수 가능(설계 §6 capability 플래그는 유지) |
| 무료로 쓸 수 있나? | **일부.** `:free` / `openrouter/free` 라우터. **일일 요청 한도**·모델 로테이션·프로덕션 SLA 비권장 |
| 주의 | 슬러그·가격·호스트 국가·data retention은 **모델 페이지 Providers 탭**에서 고를 것 |

**설계와의 정합:** `ORCHESTRATOR-DESIGN.md`의 “OpenRouter + 보완 공급사(NIM/Groq 등)” 그림은 이 조사와 **충돌하지 않는다.** 오히려 후보 풀이 Nemotron 단독보다 넓어져 창의성·사업성(티어 절감) 슬라이드를 풍부하게 만들 수 있다.

사용자 초반 프레임:

### 3-5. 특화 AI 지도 (한눈에)

```
[발견·출처]     Perplexity · Gemini/ChatGPT Deep Research
       │
[문헌·코퍼스]   Elicit · Consensus · NotebookLM(업로드 grounded)
       │
[회의·노트]     Fireflies · Notion AI
       │
[아이디어 세션] ★ IdeationEngine (각도·발산·투표·보고서)  ← 우리 코어
       │
[산출물]        Gamma / Beautiful.ai / Manus(에이전트형 전체 대행)
```

특화 AI들은 **파이프라인의 앞(조사)·뒤(덱·회의록)**에 강하고, **가운데 세션 진행**은 IdeationEngine 고유 영역이다.

## 4. IdeationEngine 적용 가능성 (구현 없음 — 평가만)

평가 축: API 성숙도 · 우리 kind(ice/idea/analyze/report)와의 거리 · 오케스트레이터 정합 · 비용·약관·심사 정직성.

### 4-1. OpenRouter LLM 풀 — **적합도 높음**

| 항목 | 평가 |
|------|------|
| 기술적 적합성 | 이미 설계된 공급사 어댑터 + 티어 레지스트리에 **슬러그 추가**면 됨 |
| 창의성 스토리 | “유명 모델 하나”가 아니라 DeepSeek/GLM/MiniMax/Nemotron/Qwen **역할별 집계**로 확장 가능 |
| 사업성(절감) | Flash·Nemotron free·gpt-oss 등으로 저가 티어 구성 → §5 정직성(가상 베이스라인·무료 $0 금지) 준수 필수 |
| 리스크 | 약관·호스트 국가·톤 불일치·`:free` 한도. §8 톤 카드·데모 프로파일과 동일 |
| 권고 시기 | 오케스트레이터 P1(레지스트리+미터 목업) → P2(실호출)에서 후보군 확정 |

**kind별 후보 스케치 (참고용, 미적용):**

| kind | 저가 후보 예 | 고가/승격 후보 예 |
|------|--------------|-------------------|
| ice | Nemotron `:free`, gpt-oss, Qwen Flash, DeepSeek Flash | (캐스케이드 금지 권고 — 설계 §4) |
| idea | DeepSeek Flash, Qwen, MiniMax(텍스트) | GLM 5.2, DeepSeek Pro |
| analyze | Qwen / DeepSeek Flash | GLM 5.2, Nemotron Ultra, (교차검증 시 2nd 모델) |
| report | — | GLM / DeepSeek Pro / (톤 중요 시 Claude급은 보완 공급사) |

### 4-2. 특화 SaaS — **코어 밖 플러그인만**

| 제품 | 적합도 | 붙는다면 어디 | 이유 / 장벽 |
|------|--------|--------------|-------------|
| **Perplexity API** | 중~고 | 보고서 전 “시장·경쟁 근거” 카드, 특정 각도(비즈니스) 보조 | API 있음. 키·비용·지연 별도. 발산 본류와는 분리하는 게 정직 |
| **Elicit API** | 저~중 | “학술 근거” 모드, 논문 해커톤 | Pro+API. 일반 팀플엔 과함 |
| **Gamma API** | 중 | report 이후 **덱보내기** | 세션 코어와 분리된 익스포트. 플랜·키 필요 |
| **Gemini (검색·요약)** | 중 | Google AI 공급사로 오케스트레이터에 이미 들어갈 수 있음 | “특화 제품”이 아니라 **LLM 공급사 하나**로 보는 편이 맞음 |
| **NotebookLM** | 낮음 | “자료 넣고 공부하기” 외부 링크 | 업로드 grounded가 강점이나 **우리 서버 파이프라인에 넣기 어려움** |
| **Notion AI** | 낮음 | 결과 Notion보내기(연동) | 정리함이지 세션 엔진이 아님 |
| **Manus** | 낮음 | 제품 대체가 됨 | 자율 에이전트가 회의 진행·각도 배분을 대신하면 IdeationEngine 정체성과 충돌 |
| **Fireflies 등** | 저~중 | 오프라인 모드 사후 요약 | 실시간 세션 SoT와는 별 트랙 |

### 4-3. 하지 말아야 할 적용 (설계·심사 관점)

1. **특화 SaaS를 “우리 멀티 LLM”이라고 발표하기** — 퍼플렉시티·감마는 LLM 라우팅이 아니라 **완제품 기능**. 창의성①과 섞으면 정직성 위반.
2. **P1에서 Perplexity+Gamma+Elicit+OpenRouter를 동시에 반쯤 붙이기** — ORCHESTRATOR §9 과설계 금지와 동일.
3. **NotebookLM/Notion을 “연동 완료”처럼 README에 쓰기** — API 없이 링크만이면 목업·예정으로만.
4. **무료 Nemotron/OR free로 사업계획 $/세션을 $0으로 고정** — §5 체크리스트 위반.

### 4-4. 장래에 쓸 때의 권장 순서 (참고)

```
지금(조사만) → P1: OpenRouter 레지스트리+미터(목업)
            → P2: DeepSeek/Nemotron/Qwen 등 실호출 + 절감 화면
            → (선택) P3+: Perplexity로 “근거 보강” 또는 Gamma로 “덱 익스포트”
            → Manus/NotebookLM은 제품 전략이 바뀌지 않는 한 비내장
```

## 7. 한 줄 결론

**덜 알려진 준수 LLM은 OpenRouter 안에서 충분히 더 고를 수 있고(DeepSeek·GLM·MiniMax·Nemotron·Qwen·Kimi 등), 작업 특화 AI도 Perplexity·Elicit·Gamma·Fireflies 등으로 확장된다. IdeationEngine에는 전자가 오케스트레이터 본류이고, 후자는 조사·덱 같은 주변 플러그인 자리이며, NotebookLM·Notion·Manus는 내장보다 외부 도구/대체 제품에 가깝다. 이번 건은 조사만 했고 프로젝트 적용은 하지 않았다.**
