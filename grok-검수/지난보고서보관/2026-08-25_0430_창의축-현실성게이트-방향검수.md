## 1. [요청①] 원인 진단

코드 실체(`adapter.js` idea):
> `[사업성][사용자경험][기술][참신함]` + 「겹치지 않는 **새** 아이디어」

| 진단 | 판정 |
|------|------|
| 참신함·“새/현존X”만 세고 실현성·수요·왜없나 부재 | **맞음** — 공상·유행어(VR·체인·운세)로 보상하는 전형적 최적화 |
| 산출 예(가상펫·꿈해몽)와 정합 | **맞음** |

**더 근본/추가 원인:**
1. **평가 축과 생성 축 불일치** — 사람은 쓸모·현실성을 보는데 생성은 참신만 최적화 → “애매함”.  
2. **2문장 상한** — 장벽·수요를 쓸 자리가 없어 공상 한 줄로 끝남.  
3. **시중검색 미연동** — “없나/왜없나”를 검증할 외부 신호가 없음(2334 C축).  
4. (부차) 블라인드 선호 뒤집힘(예전 M4:2→S4:2)은 **프롬프트뿐 아니라** 표본·평가자 편향 노이즈 — 다중 우위 기각은 OK, “단일 확정승”까지는 과신 금지.

## 2. [요청②] 현실성 게이트 타당성 · 과교정

**타당:** 공모전·해커톤 초기 아이디어에 맞음. 헬스장 Before→After 예는 **잠복 인센티브 모순**(헬스장은 안 와야 이득)을 드러내 ②번 목표(잠복니즈)와도 정합. 2228 「이미 있나? 없으면 왜?」와 **같은 지점**.

**과교정 위험 (실재):**
| 위험 | 증상 | 완화 |
|------|------|------|
| 보수화 | “상·실현가능”만 살아 **리스키닝·카피캣** | ⑤를 “기존앱 개선”이 아니라 **불편이 자연스러워진 잠복**으로 명시; ①에 “기존 강자 카피 금지” |
| ‘아직 없음’ 죽이기 | ③에서 “있으니까 기각”만 | 라벨 `이미있음/변형/공백` — **공백만 통과가 아니라** 변형+넘는법도 통과 가능 |
| 자기검열 | 발산 단계에서 ⑤까지 강제 → 폭↓ | **§4: 발산과 게이트 분리** 권고 |
| 게이트 통과 = 진실 | LLM이 ②~⑤를 지어냄 | §3 실측 |

**판정:** 게이트 **채택**. 다만 “뻔함·공상 둘 다 배제”를 **한 프롬프트에 몰아넣으면** 잠복니즈가 죽기 쉬움 → 분리 설계로 막기.

## 3. [요청③] ③⑤ LLM 추정 vs 시중검색

| 용도 | LLM 추정+라벨 | 시중검색 실측 |
|------|---------------|---------------|
| 프롬프트 실험·내부 스크리닝 | **충분**(반드시 `추정` 배지) | 불필요 |
| 사람/심사에 “왜 없나·수요”를 **근거처럼** | **부족** — 환각·광고성 이유 | **필수에 가깝다** |
| 2228/2334 C축·신선도 게이트 | 미달 | **P0과 동일 축** |

**최소 스택 (제품):**
1. LLM이 ③⑤ 초안 + **`추정` 라벨**  
2. 검색 1콜 → URL+스니펫 → `이미있음/유사/공백·미확인` (1700 안전장치)  
3. 게이트 “통과”는 **검색 라벨과 충돌하면 보류/재작성** (예: LLM “세계 최초” + 검색 “유사 다수” → 실패)

**판정:** 추정만으로 **방법론 실험은 OK**, **제품·공모전 스토리로 쓰려면 시중검색 실측이 붙어야 함**. “반드시 매 아이디어 논문급”은 과함 — **배지+링크 1~3개**면 됨.

## 4. [요청④] idea 기본 박기 vs 별도 패스

| 방식 | 장점 | 단점 |
|------|------|------|
| idea 기본에 ①~⑤ 전부 | 한 콜·단순 | 발산 폭↓·과교정·토큰↑·2문장과 충돌 |
| 발산 자유 → **현실성 검토 패스** | 폭 유지·게이트 실패작도 이견으로 보관 가능 | 콜/비용·지연 +1 |
| 하이브리드 | 균형 | 설계 약간 복잡 |

**권고: 분리(생성 → 현실성 패스)가 본선.**  
- **idea 기본:** 참신 유지하되 「공상 금지·구현 단위로」정도만 가볍게. ②~⑤ 전부 강제 ❌.  
- **`reality`/`research` 패스:** ①~⑤ + (가능하면) 시중검색. 실패는 삭제하지 말고 `dissent`/보류.  
- **quality(Self-Refine)** 와 혼동 금지 — Refine은 문장 다듬기, Reality는 장벽·수요·시중.

기본에 몰아넣는 건 **2목표 자기검증만 있는 지금**엔 과신.
