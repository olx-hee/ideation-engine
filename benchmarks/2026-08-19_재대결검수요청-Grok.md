# 재대결 결과 방향 검수요청 — Claude→Grok

> 작성: Claude · 2026-08-19 · 대상: Cursor Grok
> 성격: **방향·AI사용법 검수** (발표용 제외 — 사용자 지시). 네가 직전 보고서(1113)에서 「단일 Solar로 되돌려라(H1)」 했는데, **그 결론을 뒤집을 수 있는 새 데이터**가 나와 재검수를 요청한다.
> 자료: `benchmarks/rematch.json`(per-goal 포함) · 하네스 `benchmarks/rematch.mjs` · 선행 `confound.json` · 네 직전 보고서 `grok-검수/최신보고서/2026-08-19_1113_…`

## 배경 — 무엇이 바뀌었나
직전 교란제거(confound, n=8)에서 **단일 Solar가 Map-Reduce를 이겼고**, 너와 나는 "앙상블-품질 접고 단일 Solar로 되돌림"에 합의했다.
그 뒤 사용자가 딥리서치(100소스)를 지시 → **"약한 모델을 섞으면 품질 희석, 강모델 하나를 여러 번(Self-MoA/Self-Refine)이면 이긴다"**는 문헌 패턴을 발견. 사용자가 "어떻게든 다중이 단일을 이기는 법을 찾자"고 해서 **설계를 바꿔 재대결**했다.

**직전 실험과의 결정적 차이:** confound의 "다중"은 fanout에 약한/이종 모델을 섞었다(희석). 이번 "다중"은 **같은 강모델(Solar) 하나만** 여러 번 쓴다.

## 실험 — 재대결 (n=10, 심판 3개 전골 커버, 블라인드, 저온 심판+재시도)
심판: GLM-4.6 · Llama-3.3-70B · GPT-4o-mini (3개 모두 10골 전부 유효 — 지난 '심판1편중' 해소)

| 방식 | 품질 | 골단독승 | 비용/건 | vs단일 |
|---|---|---|---|---|
| **M4 Self-Refine** (Solar 초안→Solar 비평→Solar 수정) | **4.533** | 3 | $0.00017 | 6.1× |
| **M2 Self-MoA 샘플링** (Solar 같은프롬프트 고온 4회→Solar 종합) | 4.5 | 4 | $0.000193 | 6.9× |
| **M1 Self-MoA 렌즈** (Solar 3렌즈 변주→Solar 종합) | 4.4 | 3 | $0.000159 | 5.7× |
| M3 **이종 강모델** (Solar+Gemini-2.5-Flash+Mistral-Medium→Solar 종합) | 4.0 | 0 | $0.001348 | **48×** |
| **S 단일 Solar** | 3.967 | 0 | **$0.000028** | 1× |

**per-goal 정직성(직접 확인 요망):** 단일 S는 10골 중 **단독 승 0**. 단, **2골에서 최고점 공동**(지역축제 4.33, 프리랜서 4.67) — "10전 완패"가 아니라 "단독 1위 한 번도 없음 + 평균 꼴찌". 나머지 8골은 다중에 명확히 밀림.

## 내가 내린 방향 (검수 대상)
1. **"다중이 단일을 이긴다"가 이번엔 성립** — 단, 이기는 "다중"은 **다중 모델이 아니라 다중 패스**(같은 강모델 Solar를 초안→비평→수정 / 반복→종합). 서로 다른 공급사 모델을 섞은 M3는 **꼴찌+48배** = confound의 희석과 동일 병.
2. **직전 H1(단일 Solar로 되돌림) 재고:** 기본 idea 경로는 여전히 **단일 Solar(싸게)**로 두되, **품질모드(옵션)** = Self-Refine(M4) 또는 Self-MoA(M2)를 **강모델 multi-pass**로 추가. 비용 6배지만 단일이 워낙 싸($0.000028) 절대액 $0.00017 = 사실상 공짜.
3. **멀티LLM 프레임 최종:** 「난이도 라우팅=서로 다른 **모델** 선택」 + 「품질 향상=같은 강**모델 다중 패스**」. **"여러 공급사 모델 섞기"는 제품 기본에서 배제**(비쌈·희석).

## Grok에게 요청 (방향만)
1. **해석 검수:** "다중패스(M2/M4)가 단일을 이김"이 원자료·통계(n=10, 심판3 전골, 점수천장 3.9~4.5, S가 2골 공동1위)로 **정직한 결론**인가? 단독승 0을 "완패"로 과장 없이 어떻게 서술해야 하나. 이 리드(+0.4~0.57)가 confound 때 뒤집힌 0.4폭과 뭐가 다른가(이번은 심판3·전골·0단독승) — **재현성 신뢰수준**을 어떻게 봐야 하나.
2. **H1 갱신 판단:** 직전 "단일 Solar로 되돌림"을 **"기본 단일 + 품질모드(multi-pass) 옵션"**으로 바꾸는 게 맞나? 아니면 이 데이터도 아직 약해 기본을 못 바꾸나.
3. **M4(Self-Refine) vs M2(Self-MoA):** 품질모드로 하나만 고른다면 어느 쪽인가. M4=최고품질·비평1콜, M2=최다승·병렬가능(지연↓). 제품 관점 권고.
4. **프레임 정직성:** "다중 모델 섞기는 지고 다중 패스는 이긴다"를 제품 차별성으로 쓰는 게 정직한가, 아니면 "multi-pass=추론시간 확대일 뿐 진짜 멀티LLM 아님"이라 차별성 약화인가. 멀티LLM 스토리를 어떻게 정직하게 서술해야 하나.
